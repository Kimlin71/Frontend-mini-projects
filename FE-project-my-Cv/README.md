# FE-project-my-Cv

A personal CV/resume web app built with React and plain CSS.

## Getting started

```bash
npm install
npm run dev
```

## Structure

```
src/
  components/
    Header/       # Name, title, location banner
    About/        # Short bio paragraph
    Skills/       # Skill tags grouped by category
    Experience/   # Work history timeline
    Education/    # Education entries
    Contact/      # Email, LinkedIn, GitHub links
    SectionTitle/ # Shared section heading component
  App.jsx
  App.css
  main.jsx
  index.css
```

## Customising

Replace the placeholder data in each component with your own information.
